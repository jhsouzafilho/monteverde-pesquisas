# Portal de Pesquisas · Condomínio Monteverde (demonstração)

Página de demonstração do portal de pesquisas do Condomínio Monteverde.
Publicada em: https://jhsouzafilho.github.io/monteverde-pesquisas/

Tudo roda no navegador de quem abre o link: as respostas enviadas ficam apenas
naquele navegador, não chegam à administração, e o painel usa dados de exemplo.
A senha mostrada na tela de acesso serve só para conhecer o painel.

O portal completo — com servidor, coleta real das respostas e exportação em CSV —
fica na instalação do condomínio.
